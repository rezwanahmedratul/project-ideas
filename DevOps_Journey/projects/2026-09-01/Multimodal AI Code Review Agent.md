**日期**: 2026-09-01  
**类别**: AI ML  
**难度**: 中级

## 概述

构建一个支持代码、文档、测试用例多维度审查的 AI Agent。不仅能检查代码质量，还能验证文档一致性、评估测试覆盖率，并给出结构化改进建议。

## 审查维度

### 1. 代码质量
- **静态分析**: ESLint/Pylint/RustClippy 规则集成
- **安全扫描**: 注入漏洞、硬编码密钥、依赖漏洞
- **复杂度分析**: 圈复杂度、认知复杂度、重复代码检测

### 2. 文档一致性
- API 文档与代码签名是否匹配
- README 示例是否可运行
- 注释是否与实现逻辑一致

### 3. 测试覆盖
- 单元测试覆盖率统计
- 边界条件测试缺失识别
- Mock 滥用检测

## 工具栈

- **LLM**: Claude 3.5 Sonnet / GPT-4o (代码理解)
- **静态分析**: sonarqube / golangci-lint / ruff
- **覆盖率**: coverage.py / rust-coveralls
- **向量存储**: ChromaDB (历史审查记录检索)
- **集成**: GitHub App / GitLab MR Hook
