**难度**: 中级

## 概述

基于 Proxmox VE 构建完整的集群自动化运维平台，实现虚拟机生命周期管理、资源动态调度、故障自愈和容量预测。

## 工作流

1. **监控采集**: 每30秒收集各节点 CPU/MEM/磁盘/网络指标
2. **预测分析**: 使用时间序列模型预测未来7天容量需求
3. **智能调度**: 根据预测结果自动迁移 VM 到合适节点
4. **故障检测**: 实时监控健康状态，异常时触发告警
5. **自愈执行**: 重启故障 VM、迁移受损容器、切换备用节点

## 工具栈

- **后端**: Python FastAPI
- **PVE SDK**: proxmox-api-python
- **时序数据**: InfluxDB + Telegraf
- **调度器**: Celery + Redis
- **监控**: Prometheus Node Exporter
- **通知**: Telegram Bot API
