# AI 辅助的 CI/CD 管道修复助手

**日期**: 2026-09-01  
**类别**: Software Development  
**难度**: 中级  
**预计工期**: 2-3周

---

## 概述

构建一个集成在 Jenkins/GitHub Actions 中的 AI 助手，当流水线失败时自动分析错误日志、定位根因、生成修复建议，并可一键应用修复。

---

## 功能特性

| 功能 | 描述 |
|------|------|
| **智能分类** | 自动识别错误类型（编译错误、测试失败、镜像拉取失败等） |
| **根因推荐** | 基于历史数据和 LLM 推理给出最可能的原因 |
| **修复建议** | 生成可执行的代码补丁或配置变更 |
| **自动 PR** | 直接在 Git 仓库创建修复 Pull Request |
| **知识库积累** | 每次修复自动入库，越用越准 |

---

## 工具栈

- **后端**: Python FastAPI
- **LLM**: OpenAI API / Claude API (可选本地 LLM)
- **向量库**: ChromaDB / Qdrant
- **CI 集成**: Jenkins Plugin / GitHub Actions
- **Git 操作**: PyGithub / python-gitlab
- **日志解析**: 自定义 Regex + LLM 提取
