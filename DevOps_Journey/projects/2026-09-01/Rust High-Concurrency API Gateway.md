## 概述

使用 Rust 构建一个高性能 HTTP API 网关，支持路由分发、限流熔断、认证鉴权、请求缓存和负载均衡。目标 QPS > 50,000。

## 核心模块

### 1. 路由分发器
- 支持路径参数、正则匹配、子域名路由
- 动态路由注册（热加载）
- 请求重写和路径标准化

### 2. 限流熔断器
- Token Bucket / Sliding Window 算法
- 熔断器模式（Closed → Open → Half-Open）
- 分级限流（用户级/IP级/全局）

### 3. 认证鉴权
- JWT 验证 + 刷新令牌
- OAuth 2.0 / OpenID Connect 代理
- RBAC 权限中间件

### 4. 请求缓存
- 多级缓存（L1 内存 + L2 Redis）
- Cache-Control 语义支持
- 缓存预热和失效策略

## 工具栈

- **语言**: Rust 1.75+
- **Web框架**: Axum 0.7 + Tokio
- **中间件**: Tower
- **认证**: jsonwebtoken + argon2
- **缓存**: redis + moka (本地缓存)
- **监控**: Prometheus metrics + tracing
- **测试**: cargo-test + k6 压测
