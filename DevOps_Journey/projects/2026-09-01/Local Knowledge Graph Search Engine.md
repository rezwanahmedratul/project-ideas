# 本地知识图谱搜索引擎

**日期**: 2026-09-01  
**类别**: AI ML  
**难度**: 中级  
**预计工期**: 2-3周

---

## 概述

构建一个基于本地 LLM 和向量数据库的知识图谱搜索引擎。支持自然语言问答、实体关系发现、上下文记忆，适用于个人知识管理和研究辅助。

## 核心功能

### 1. 多源数据摄入
- 自动从 Obsidian vault 读取笔记
- 支持导入 PDF、网页、API 数据源
- 增量更新，避免重复处理

### 2. 知识抽取
- **命名实体识别**: 人名、地点、组织、概念
- **关系抽取**: "创建于"、"位于"、"属于"等关系
- **事件抽取**: 时间线化的事件记录

### 3. 智能搜索
- **语义搜索**: 自然语言查询 → 相关实体
- **图谱遍历**: 沿关系边探索关联知识
- **混合检索**: 向量相似度 + 图谱结构 + 关键词

### 4. 问答系统
- **RAG 增强**: 检索相关知识 + LLM 生成
- **溯源引用**: 每个回答附带出处链接
- **对话记忆**: 多轮问答保持上下文

## 工具栈

- **LLM**: Ollama (本地) / Claude API (云端)
- **向量库**: ChromaDB (嵌入式)
- **图谱数据库**: Neo4j (Docker)
- **NLP**: spaCy / HuggingFace Transformers
- **前端**: Streamlit / Gradio
- **摄取**: Beautiful Soup / pdfplumber
