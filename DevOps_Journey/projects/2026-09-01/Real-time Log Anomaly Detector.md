## 概述

构建一个流式日志分析系统，实时检测应用日志中的异常模式（错误激增、性能退化、安全事件），并自动触发分级告警。

## 检测能力

### 1. 错误模式检测
- **突增检测**: 错误日志数量短时间内显著上升
- **新模式**: 出现从未见过的错误类型
- **级联故障**: 多个服务的错误开始相互关联

### 2. 性能退化检测
- **延迟异常**: P99 延迟突然升高
- **吞吐下降**: 请求处理能力降低
- **资源耗尽**: CPU/内存/连接池接近上限

### 3. 安全事件检测
- **暴力破解**: 同一 IP 多次登录失败
- **异常访问**: 非工作时间的大规模数据访问
- **注入攻击**: SQL/命令注入特征匹配

## 技术实现

### 流处理管道
```
Filebeat/Fluent Bit → Kafka → Spark Streaming/Flink → 规则引擎 → 告警
```

### 异常检测算法
| 算法 | 适用场景 | 延迟 |
|------|---------|------|
| **滑动窗口统计** | 简单阈值异常 | 毫秒级 |
| **Isolation Forest** | 多维度异常 | 秒级 |
| **LSTM 自编码器** | 时序模式异常 | 分钟级 |
| **LLM 语义分析** | 复杂错误归类 | 秒级 |

## 工具栈

- **日志采集**: Fluent Bit / Filebeat
- **消息队列**: Apache Kafka / Redpanda
- **流处理**: Apache Flink / Faust (Python)
- **检测引擎**: PyOD (Python 异常检测库)
- **告警路由**: Alertmanager / PagerDuty
- **可视化**: Grafana / Kibana
