# IaC 变更影响预测平台

**日期**: 2026-09-01  
**类别**: Combined  
**难度**: 高级  
**预计工期**: 4周

---

## 概述

构建一个分析 Terraform/Pulumi 基础设施变更影响的智能平台。通过语义分析和依赖图谱，预测变更可能带来的风险和副作用，在应用前提供预警。

## 分析维度

### 1. 安全风险
- 公开暴露的端口/存储桶
- 硬编码密钥或凭据
- 不符合安全最佳实践的配置
- 违反合规要求的设置

### 2. 成本影响
- 新增资源的月度费用估算
- 资源类型变更的成本变化
- 保留实例/预留容量的影响
- 跨可用区/区域迁移费用

### 3. 可用性风险
- 单点故障引入
- 依赖链断裂风险
- 容量不足预判
- 备份/恢复能力下降

## 工作流程

```
输入: terraform plan JSON
         │
         ▼
┌──────────────────┐
│ 1. 变更提取       │ ← Parse diff
│    - 新增资源     │
│    - 修改属性     │
│    - 删除资源     │
└────────┬─────────┘
         ▼
┌──────────────────┐
│ 2. 依赖分析       │ ← Build dependency graph
│    - 上游依赖     │
│    - 下游影响     │
└────────┬─────────┘
         ▼
┌──────────────────┐
│ 3. 风险评估       │ ← Rule-based + LLM
│    - 安全规则检查 │
│    - 成本预测     │
│    - 影响传播     │
└────────┬─────────┘
         ▼
┌──────────────────┐
│ 4. 报告生成       │ ← Structured output
│    - JSON report  │
│    - 可视化面板   │
│    - Slack 通知   │
└──────────────────┘
```

## 工具栈

- **IaC 解析**: go-cty / hcl2json / terraform-json
- **图谱分析**: NetworkX (Python) / Neo4j
- **风险评估**: Rule Engine (Pydantic) + LLM 辅助
- **成本估算**: Cloud pricing APIs (AWS/GCP/Azure)
- **集成**: GitHub App / GitLab MR Bot
- **展示**: Streamlit / Plotly Dash
