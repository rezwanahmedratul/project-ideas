# AI 驱动的代码审查助手

## 概述
开发一个集成到 GitHub PR 流程中的 AI 代码审查工具，自动生成审查意见和改进建议。

## 架构/结构
```
┌─────────────────────────────────────────────────────────┐
│               AI Code Review Assistant                   │
├──────────────┬──────────────┬──────────────┬────────────┤
│  PR 监听器   │  AI 分析引擎  │  评论生成器  │  统计面板  │
└──────┬───────┴──────┬───────┴──────┬───────┴─────┬─────┘
       │              │              │             │
       ▼              ▼              ▼             ▼
  GitHub Webhook   LLM API       GitHub API   Dashboard
                   (代码理解)     (发布评论)   (趋势分析)
```

## 工作流
1. 监听 GitHub Pull Request 事件
2. 提取代码 diff 并提交给 AI 模型
3. AI 分析：安全问题、性能瓶颈、代码风格
4. 生成结构化评论并自动发布到 PR
5. 记录审查统计数据供团队回顾

## 工具
- Python + GitHub API
- LangChain / OpenAI API
- FastAPI（Webhook 处理）
- SQLite（数据存储）

## 学习目标
- GitHub Webhook 开发
- AI 辅助编程实践
- 代码静态分析基础
- API 集成与设计
