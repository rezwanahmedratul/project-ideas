# 实时日志聚合与分析平台

## 概述
构建一个轻量级日志聚合系统，支持实时采集、搜索和分析应用程序日志。

## 架构/结构
```
┌─────────────────────────────────────────────────────────┐
│                  日志聚合平台                             │
├──────────────┬──────────────┬──────────────┬────────────┤
│  采集层      │  存储层      │  查询层      │  展示层    │
│  Collectors  │  Storage     │  Query       │  UI        │
└──────┬───────┴──────┬───────┴──────┬───────┴─────┬─────┘
       │              │              │             │
  Filebeat      Elasticsearch    Loki          Grafana
  Fluentd       ClickHouse       Thanos        Kibana
       │              │              │             │
       ▼              ▼              ▼             ▼
  多源日志         持久化         高性能查询     可视化
```

## 工作流
1. Filebeat/Fluentd 从各服务采集日志
2. 日志经过解析和富化后写入存储
3. 用户通过 KQL/Lucene 语法查询
4. Grafana/Kibana 展示实时仪表板

## 工具
- Elasticsearch 或 Loki
- Filebeat / Fluentd
- Kibana 或 Grafana
- Docker Compose（部署）

## 学习目标
- 日志管理最佳实践
- 搜索引擎原理
- 分布式系统设计
- 数据可视化
