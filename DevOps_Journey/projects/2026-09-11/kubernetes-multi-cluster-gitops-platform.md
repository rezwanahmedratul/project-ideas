# Kubernetes 多集群 GitOps 管理平台

## 概述
构建一个基于 ArgoCD 的多集群 Kubernetes 管理面板，支持从单一控制平面部署和管理多个 K8s 集群。

## 架构/结构
```
┌─────────────────┐     Git      ┌─────────────────┐
│  Git Repository  │ ◄──────────► │  ArgoCD Server  │
│  (应用配置)       │              │  (控制平面)      │
└─────────────────┘              └────────┬────────┘
                                          │
                    ┌─────────────────────┼─────────────────────┐
                    ▼                     ▼                     ▼
              ┌──────────┐         ┌──────────┐         ┌──────────┐
              │ Cluster A │         │ Cluster B │         │ Cluster C │
              │(AWS EKS) │         │(GCP GKE) │         │(本地 Proxmox)│
              └──────────┘         └──────────┘         └──────────┘
```

## 工作流
1. 开发者在 Git 仓库提交 Helm Chart + Kustomize 配置
2. ArgoCD 自动检测变更并同步到目标集群
3. 控制面板展示所有集群的健康状态和部署历史
4. 支持回滚和审计日志

## 工具
- Kubernetes + ArgoCD
- Helm / Kustomize
- Terraform（集群基础设施）
- Prometheus + Grafana（监控）

## 学习目标
- GitOps 原理与实现
- 多集群管理策略
- Helm Chart 最佳实践
- CI/CD 流水线设计
