# 本地 LLM 推理服务部署平台

## 概述
基于 Ollama + vLLM 构建本地大模型推理服务，支持多模型并发和 API 统一管理。

## 架构/结构
```
┌─────────────────────────────────────────────────────────┐
│              Local LLM Inference Platform                │
├──────────────┬──────────────┬──────────────┬────────────┤
│  API 网关    │  模型管理层  │  推理引擎    │  监控层    │
├──────────────┼──────────────┼──────────────┼────────────┤
│ • OpenAI 兼容│ • 模型加载   │ • Ollama     │ • 指标采集 │
│   REST API   │ • 版本管理   │ • vLLM       │ • 日志记录 │
│ • 路由转发   │ • 量化选择   │ • TensorRT   │ • 告警     │
│ • 认证鉴权   │ • 资源分配   │ • GGUF       │            │
└──────────────┴──────────────┴──────────────┴────────────┘
```

## 工作流
1. 管理员通过 UI 选择并加载模型
2. 系统自动分配 GPU/CPU 资源
3. 提供 OpenAI 兼容 API 端点
4. 实时监控推理性能和资源使用

## 工具
- Ollama / vLLM
- Docker / Kubernetes
- FastAPI（API 网关）
- Prometheus + Grafana

## 学习目标
- 本地模型部署
- GPU 资源管理
- OpenAI API 协议
- 推理性能优化
