# 容器镜像安全扫描 CI 插件

## 概述
开发一个 CI/CD 插件，在构建流程中自动扫描容器镜像的安全漏洞。

## 架构/结构
```
┌─────────────────────────────────────────────────────────┐
│             Container Image Security Scanner             │
├──────────────┬──────────────┬──────────────┬────────────┤
│  集成层      │  扫描引擎    │  报告生成    │  阻断策略  │
├──────────────┼──────────────┼──────────────┼────────────┤
│ • GitHub     │ • Trivy      │ • SARIF     │ • 阈值检查 │
│   Actions    │ • Grype      │ • HTML      │ • 失败策略 │
│ • Jenkins    │ • Clair      │ • JSON      │ • 通知     │
│ • GitLab CI  │ • Anchore    │             │            │
└──────────────┴──────────────┴──────────────┴────────────┘
```

## 工作流
1. CI 触发镜像构建
2. 自动运行安全扫描
3. 生成漏洞报告
4. 根据策略决定继续或中止流水线

## 工具
- Go / Python
- Trivy / Grype / Clair
- GitHub Actions API
- SARIF 格式

## 学习目标
- 容器安全知识
- CI/CD 插件开发
- 漏洞管理流程
- 安全即代码实践
