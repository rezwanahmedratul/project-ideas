# Go 高并发 API 网关

## 概述
使用 Go 语言构建一个支持限流、认证、路由的高性能 API 网关。

## 架构/结构
```
┌─────────────────────────────────────────────────────────┐
│                   API Gateway                            │
├──────────────┬──────────────┬──────────────┬────────────┤
│  请求入口    │  核心处理    │  后端路由    │  响应返回  │
├──────────────┼──────────────┼──────────────┼────────────┤
│ • TLS 终止   │ • 认证鉴权   │ • 动态路由   │ • 压缩     │
│ • 负载均衡   │ • 限流熔断   │ • 服务发现   │ • CORS     │
│ • 请求日志   │ • 缓存层     │ • 负载分发   │ • 错误处理 │
└──────────────┴──────────────┴──────────────┴────────────┘
```

## 工作流
1. 客户端请求到达网关
2. 执行认证和限流检查
3. 根据路由规则转发到后端服务
4. 聚合响应并返回客户端

## 工具
- Go + Gin/Fiber
- Redis（缓存/限流）
- Consul/Etcd（服务发现）
- Prometheus（监控）

## 学习目标
- Go 并发编程
- API 网关设计模式
- 分布式系统基础
- 性能优化技巧
