# 软件开发项目 3：CLI 终端天气与待办提醒工具

**日期：** 2026-09-21  
**分类：** 软件开发 / CLI / Python

---

## 📋 概述
开发一款命令行工具，整合天气查询和待办事项管理，支持终端实时刷新显示，适合日常快速查看。

## 🏗️ 架构设计
```
┌─────────────────────────────────────────────────────────────┐
│                    Terminal TUI (Python)                     │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  ┌─────────────┐      ┌─────────────┐               │   │
│  │  │  Weather    │      │   Todo List │               │   │
│  │  │  🌤️ 24°C   │      │  ✓ 会议 10点│               │   │
│  │  │  ☁️ 多云    │      │  ○ 提交PR   │               │   │
│  │  │  🌧️ 60%降水 │      │  ○ 写文档   │               │   │
│  │  └─────────────┘      └─────────────┘               │   │
│  └─────────────────────────────────────────────────────┘   │
│  [刷新] [添加任务] [删除] [设置位置]                        │
└─────────────────────────────────────────────────────────────┘
```

## 🛠️ 技术栈
- **语言：** Python 3.11+
- **TUI 框架：** Textual 或 Rich
- **天气 API：** Open-Meteo (免费无需 Key) 或 OpenWeatherMap
- **数据存储：** SQLite / JSON 文件
- **安装：** pip install / Homebrew

## 📚 学习目标
- 掌握 Python TUI 开发
- 学习异步 HTTP 请求 (httpx/aiohttp)
- 理解 SQLite 简单 CRUD 操作
