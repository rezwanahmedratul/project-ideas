# AI/ML 项目 2：AI 驱动的代码质量分析器

**日期：** 2026-09-21  
**分类：** AI/ML / 代码分析 / LLM

---

## 📋 概述
开发一款 AI 驱动的代码质量分析工具，结合静态分析和 LLM 推理，检测代码异味、潜在 Bug 和安全漏洞。

## 🏗️ 架构设计
```
┌─────────────────────────────────────────────────────────────┐
│                    Code Analyzer Pipeline                    │
│                                                              │
│  ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐  │
│  │ Source  │───▶│ Static  │───▶│  LLM    │───▶│ Report  │  │
│  │ Code    │    │ Analysis│    │ Review  │    │ Gen     │  │
│  └─────────┘    └────┬────┘    └────┬────┘    └─────────┘  │
│                      │             │                        │
│                  ┌───┴───┐     ┌───┴───┐                    │
│                  │ Sonar │     │ Ollama│                    │
│                  │Qube   │     │ GPT   │                    │
│                  └───────┘     └───────┘                    │
└─────────────────────────────────────────────────────────────┘
```

## 🛠️ 技术栈
- **静态分析：** SonarQube / Semgrep / Bandit
- **LLM：** Ollama (CodeLlama-13B) 或 OpenRouter
- **数据处理：**树形 AST 解析 (Tree-sitter)
- **输出：** HTML 报告 + JSON 结构化数据

## 📚 学习目标
- 理解 AST（抽象语法树）分析与代码度量
- 学习如何将代码片段转换为 LLM 可用上下文
- 掌握多工具结果融合与去重
