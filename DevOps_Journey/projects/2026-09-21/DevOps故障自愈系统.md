# 综合项目 2：DevOps 故障自愈系统

**日期：** 2026-09-21  
**分类：** DevOps + AI / 可观测性 / 自动化运维

---

## 📋 概述
构建一个基于 AI 的故障自愈系统，当监控告警触发时，自动分析日志、诊断根因并执行预设修复动作。

│  │ Alert   │───▶│ Log     │───▶│ Root    │───▶│ Fix     │  │
│  │ (PagerDuty│   │ Aggregation│   │ Cause   │   │ Action  │  │

## 🛠️ 技术栈
- **监控：** Prometheus + Alertmanager
- **日志：** Loki / ELK Stack
- **AI 引擎：** LangChain + LLM (Claude/GPT)
- **执行：** Kubernetes Job / Shell Script
- **知识库：** Runbook 文档 + 历史故障记录

## 📚 学习目标
- 理解 Incident Response 闭环流程
- 学习 AIOps（AI for IT Operations）方法
- 掌握安全边界内的自动化执行设计
