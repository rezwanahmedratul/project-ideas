# 软件开发项目 2：个人知识管理系统（Obsidian + Python）

**日期：** 2026-09-21  
**分类：** 软件开发 / 生产力工具 / Python

## 📋 概述
基于 Obsidian 构建个人知识管理系统，使用 Python 脚本自动化笔记整理、标签分类和每日摘要生成。

## 🏗️ 架构设计
```
┌─────────────────────────────────────────────────────────────┐

│  └──────┬──────┘  └──────┬──────┘  └──────┬──────┘         │
│         │                │                │                 │
│         └────────────────┼────────────────┘                 │
│                          ↓                                  │
│              ┌─────────────────────┐                        │
│              │  Python Auto-MTagger│                        │
│              │  - 标签提取          │                        │
│              │  - 双向链接生成      │                        │
│              │  - 摘要报告          │                        │
│              └─────────────────────┘                        │
└─────────────────────────────────────────────────────────────┘
```

## 🛠️ 技术栈
- **核心工具：** Obsidian
- **自动化：** Python 3.11+
- **NLP：** spaCy / transformers (可选)
- **调度：** cron / GitHub Actions
- **版本控制：** Git + Obsidian Git 插件

## 📚 学习目标
- 掌握 Obsidian Dataview 插件高级用法
- 学习 Python 文件操作与 Markdown 解析
- 理解双向链接与知识图谱原理
