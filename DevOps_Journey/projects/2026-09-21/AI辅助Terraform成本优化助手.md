# 综合项目 3：AI 辅助的 Terraform 成本优化助手

**日期：** 2026-09-21  
**分类：** DevOps + AI / FinOps / Terraform

---

## 📋 概述
开发一款 Terraform 插件/脚本，扫描基础设施配置并使用 LLM 识别成本浪费，给出优化建议和改写后的 HCL 代码。

## 🏗️ 架构设计
```
┌─────────────────────────────────────────────────────────────┐
│              Terraform Cost Optimizer                        │
│                                                              │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐     │
│  │ TF Plan     │───▶│ Cost        │───▶│ LLM         │     │
│  │ Output      │    │ Estimation  │    │ Suggestions │     │
│  └─────────────┘    └─────────────┘    └──────┬──────┘     │
│                                               │             │
│                                         ┌─────┴─────┐     │
│                                         │ Optimized │     │
│                                         │ TF Code   │     │
│                                         └───────────┘     │
└─────────────────────────────────────────────────────────────┘
```

## 🛠️ 技术栈
- **TF 集成：** terraform plan JSON 输出解析
- **成本估算：** AWS Pricing API / Azure Cost Management API
- **AI 引擎：** GPT-4o / Claude 3.5 Sonnet
- **输出：** 对比报告 + 优化后 .tf 文件
