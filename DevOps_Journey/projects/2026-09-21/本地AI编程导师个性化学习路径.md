# 综合项目 4：本地 AI 编程导师（个性化学习路径）

**日期：** 2026-09-21  
**分类：** AI/ML + Education / 个性化学习 / RAG

---

## 📋 概述
构建一个本地运行的 AI 编程导师，根据你的学习进度和项目经验，生成个性化的学习路径和实战练习。

## 🏗️ 架构设计
```
┌─────────────────────────────────────────────────────────────┐
│                  AI Programming Tutor                        │
│                                                              │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐     │
│  │ User        │───▶│ Knowledge   │───▶│ Learning    │     │
│  │ Profile     │    │ Graph       │    │ Path Gen    │     │
│  └─────────────┘    └─────────────┘    └──────┬──────┘     │
│                                               │             │
│  ┌─────────────┐    ┌─────────────┐           │             │
│  │ Practice    │◀───│ Exercise    │◀─────────┘             │
│  │ Problems    │    │ Generator   │                        │
│  └─────────────┘    └─────────────┘                        │
│           ▲                      │                         │
│           └──────────────────────┘                         │
│                   Code Review Loop                         │
└─────────────────────────────────────────────────────────────┘
```

## 🛠️ 技术栈
- **LLM：** Ollama (Llama-3.1-8B / Phi-3.5)
- **知识管理：** Obsidian + Dataview
- **代码执行：** Code Interpreter (本地 Docker 容器)
- **界面：** Streamlit Web App

## 📚 学习目标
- 学习个性化推荐系统原理
- 掌握项目式学习（PBL）设计
- 理解代码自动评测机制

## 🎯 构建里程碑
| 阶段 | 任务 | 预计时间 |
|------|------|----------|
| M1 | 学习者画像与技能图谱 | 2h |
| M2 | 知识点关联与难度分级 | 2h |

| M4 | 代码评测沙箱 | 2h |
| M5 | Web UI 与进度追踪 | 3h |
