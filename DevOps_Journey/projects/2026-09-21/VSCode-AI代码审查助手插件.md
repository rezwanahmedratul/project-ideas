# 软件开发项目 1：VS Code 插件 — AI 代码审查助手

**日期：** 2026-09-21  
**分类：** 软件开发 / VS Code Extension / AI

---

## 📋 概述
开发一款 VS Code 扩展，实时分析代码变更并调用本地/云端 LLM 进行智能 Code Review，提供安全漏洞、性能问题和代码风格建议。

## 🏗️ 架构设计
```
┌─────────────────────────────────────────────────────────────┐
│                     VS Code Extension                        │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │ Diff Viewer │  │ AI Analyzer │  │ Comment UI  │         │
│  └──────┬──────┘  └──────┬──────┘  └──────┬──────┘         │
│         │                │                │                 │
│         └────────────────┼────────────────┘                 │
│                          ↓                                  │
│              ┌─────────────────────┐                        │
│              │  Local/Cloud LLM API │                        │
│              │  (Ollama / OpenAI)   │                        │
│              └─────────────────────┘                        │
└─────────────────────────────────────────────────────────────┘
```

## 🛠️ 技术栈
- **插件开发：** TypeScript + VS Code API
- **AI 引擎：** Ollama (本地) 或 OpenAI API (云端)
- **Diff 解析：** simple-git 或 vscode.diff
- **存储：** vscode.workspaceState (轻量)

## 📚 学习目标
- 掌握 VS Code Extension API 核心概念
- 学习如何在扩展中调用外部 API
- 理解 Diff 解析与代码上下文提取
