    cart = Cart([Item(10), Item(20)])
    
    # Expected cases identified by AI

## Best Practices

1. **Start with critical paths**: Focus AI testing on payment, auth, and data flow
2. **Combine approaches**: Use AI-generated tests alongside hand-written ones
3. **Monitor AI confidence**: Review low-confidence test generations
4. **Maintain test data**: Use AI to generate realistic but safe test data
5. **Integrate early**: Add AI testing to PR workflow, not just CI

## Challenges and Limitations

- **False positives**: AI may generate unnecessary tests
- **Context limits**: AI struggles with very large codebases
- **Over-reliance**: Teams may neglect writing fundamental tests
- **Security concerns**: AI-generated tests may expose sensitive data
