## Overview

Small Language Models (SLMs) — typically 0.5B to 14B parameters — are enabling sophisticated AI on consumer hardware, edge devices, and embedded systems in 2026.

## What Makes SLMs Different

- Designed for specific tasks rather than general purposes
- Run efficiently on:
  - Raspberry Pi
  - NVIDIA Jetson Nano
  - Mobile NPUs
  - Microcontroller-class hardware
- Fine-tuned versions can match or beat larger models on narrow tasks

## 2026 SLM Landscape

### Leading Models
- **Phi-3 series** (Microsoft) — 3.8B and smaller variants
- **Gemma 2B/9B** (Google) — open-weight, efficient
- **Llama 3.2** — optimized for edge deployment
- **Qwen series** — strong multilingual support

### Performance Characteristics

| Model Size | Typical Use Case | Latency | Hardware |
|------------|------------------|---------|----------|
| 0.5B-1B | Chatbots, simple QA | <50ms | Mobile |
| 2B-4B | Code completion, reasoning | 100-200ms | Jetson |
| 7B-14B | Complex tasks, agents | 200-500ms | Desktop GPU |

## Why SLMs Dominate Agentic AI

1. **Responsiveness** — Single user's agent feels instant
2. **Cost efficiency** — Lower inference costs
3. **Privacy** — Local processing, no cloud dependency
4. **Reliability** — Works offline, no network dependence

## Fine-Tuning Insights (2026)

- Task-specific fine-tuning outperforms general models
- Honest measurement and benchmarking essential
- Quantization techniques improve efficiency without quality loss
