## LangGraph: State Machine Approach

LangGraph represents agent workflows as directed graphs where nodes are agents/LLMs and edges are conditional transitions.

**Strengths:**
- Fine-grained control over execution flow
- Built-in checkpointing and human-in-the-loop support
- Easy visualization of agent interactions
- Pydantic-based state management

**Use cases:**
- Customer support pipelines with escalation paths
- Research agents that iterate through hypothesis generation
- Code review pipelines with multi-stage validation

```python
# Simplified LangGraph pattern
from langgraph.graph import StateGraph, END

workflow = StateGraph(InputOutput)
workflow.add_node("researcher", research_agent)
workflow.add_node("writer", write_agent)
workflow.add_node("reviewer", review_agent)
workflow.add_edge("researcher", "writer")
workflow.add_conditional_edges("writer", decide_review, {"needs_review": "reviewer", "done": END})
```

## CrewAI: Role-Based Collaboration

CrewAI uses a team metaphor — agents have roles, goals, and backstories, working together in crews.

**Strengths:**
- Intuitive mental model (agents = employees)
- Fast prototyping with minimal code
- Built-in task delegation and handoff
- Great documentation and templates

**Use cases:**
- Content generation pipelines (researcher → writer → editor)
- Market research teams
- Automated code review crews

```python
# Simplified CrewAI pattern
from crewai import Agent, Task, Crew

researcher = Agent(role="Researcher", goal="Find latest AI trends")
writer = Agent(role="Writer", goal="Write clear summaries")
task = Task(description="Research and summarize...", agent=researcher)
crew = Crew(agents=[researcher, writer], tasks=[task])
```

## AutoGen: Conversation-Based Orchestration

AutoGen (Microsoft) focuses on multi-agent conversations where agents talk to each other to solve problems.

**Strengths:**
- Natural conversation flow between agents
- Strong Python ecosystem integration
- Code execution capability built-in
- Excellent for research and debugging

**Use cases:**
- Multi-agent code generation and debugging
- Automated software testing
- Research assistance with tool use
