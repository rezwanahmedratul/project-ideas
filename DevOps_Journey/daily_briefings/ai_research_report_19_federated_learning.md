## Core Concepts

### How Federated Learning Works

```
┌──────────┐     ┌──────────┐     ┌──────────┐
│ Device 1 │     │ Device 2 │     │ Device N │
│  (Local) │     │  (Local) │     │  (Local) │
└────┬─────┘     └────┬─────┘     └────┬─────┘
     │                │                │
     └────────────────┼────────────────┘
                      │
              ┌───────▼───────┐
              │  Federated    │
              │  Aggregator   │
              │  (Server)     │
              └───────────────┘
```

1. Server sends global model to devices
2. Each device trains locally on private data
3. Devices send model updates (not raw data) to server
4. Server aggregates updates (FedAvg, FedAdam, etc.)
5. Repeat until convergence

## Privacy Techniques

| Technique | Description | Trade-offs |
|-----------|-------------|------------|
| **Differential Privacy** | Add noise to gradients | Privacy vs. accuracy |
| **Secure Multi-Party Computation** | Encrypted aggregation | Communication overhead |
| **Homomorphic Encryption** | Compute on encrypted data | Computational cost |
| **Trust Regions** | Bound update magnitude | Simplicity vs. privacy |
| **Local Differential Privacy** | Noise at device level | Maximum privacy, max noise |
